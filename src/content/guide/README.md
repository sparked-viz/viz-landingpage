# Sparked Viz — User Guide

This guide covers Sparked Viz end to end: building a visual explanation in the **Editor**, then presenting and recording it in **Explanar** (LMS mode). It's organized to match the order you'd actually work in — create, then edit, then animate, then organize into steps, then record. The full reference for every object type lives inside [Object Types](editor/02-object-types.md), and for every animation type inside [Animation Types](editor/06-animation-types.md).
