# Object Types

Every object you can add to a scene, grouped the same way as the Add Object Bar. Expand a category to see what's inside and how to create it.

## Geometry

33 types across six subcategories, all reachable from the **Geometry** tab of the Add Object Bar.

<details>
<summary>Primitives (4)</summary>

<details>
<summary><img src="/guide-icons/geometry_point.svg" alt="Point icon" /> Point</summary>

A single labeled point — the basic building block most other Geometry objects snap to.

**How to create it:**
1. Click to place the point.

</details>

<details>
<summary><img src="/guide-icons/geometry_segment.svg" alt="Segment icon" /> Segment</summary>

A straight line between two points.

**How to create it:**
1. Click to set the start (snaps to existing points).
2. Click to set the end.

</details>

<details>
<summary><img src="/guide-icons/geometry_dashed_segment.svg" alt="Dashed Segment icon" /> Dashed Segment</summary>

The same as a Segment, drawn with a dashed stroke.

**How to create it:**
1. Click to set the start (snaps to existing points).
2. Click to set the end.

</details>

<details>
<summary><img src="/guide-icons/geometry_circle.svg" alt="Circle icon" /> Circle</summary>

A circle defined by its center and a point on its edge.

**How to create it:**
1. Click to set the center.
2. Click to set a point on the circle — this defines the radius.

</details>

</details>

<details>
<summary>Annotations (4)</summary>

<details>
<summary><img src="/guide-icons/geometry_label.svg" alt="Label icon" /> Label</summary>

A letter label or live measurement attached to an existing point, segment, or angle.

**How to create it:**
1. Hover over a point, segment, or angle.
2. Click to attach the next free letter label — or `Alt`-click a segment or angle to attach a live length/angle measurement instead.
3. Click empty canvas to stop placing labels.

</details>

<details>
<summary><img src="/guide-icons/geometry_angle.svg" alt="Angle icon" /> Angle</summary>

An arc marking the angle between two rays from a shared vertex.

**How to create it:**
1. Select or place the vertex.
2. Select or place a point on the first ray.
3. Select or place a point on the second ray.

</details>

<details>
<summary><img src="/guide-icons/geometry_right_angle.svg" alt="Right Angle icon" /> Right Angle</summary>

The same three clicks as Angle, but draws the small square right-angle marker instead of an arc.

**How to create it:**
1. Select or place the vertex.
2. Select or place a point on the first ray.
3. Select or place a point on the second ray.

</details>

<details>
<summary><img src="/guide-icons/geometry_measure.svg" alt="Segment Length icon" /> Segment Length</summary>

A dimension line measuring the distance between two points.

**How to create it:**
1. Click to set the measurement start.
2. Click to set the measurement end.
3. Click to offset the measurement line to either side.

</details>

</details>

<details>
<summary>Polygons (8)</summary>

<details>
<summary><img src="/guide-icons/geometry_triangle.svg" alt="Triangle icon" /> Triangle</summary>

**How to create it:**
1. Click to set vertex 1.
2. Click to set vertex 2.
3. Click to set vertex 3.

</details>

<details>
<summary><img src="/guide-icons/geometry_right_triangle.svg" alt="Right Triangle icon" /> Right Triangle</summary>

A triangle with a right angle built into its construction.

**How to create it:**
1. Click to set the first leg's endpoint.
2. Click to set the right-angle vertex.
3. Click to set the second leg's length and side.

</details>

<details>
<summary><img src="/guide-icons/geometry_quadrilateral.svg" alt="Quadrilateral icon" /> Quadrilateral</summary>

**How to create it:**
1. Click to set vertex 1.
2. Click to set vertex 2.
3. Click to set vertex 3.
4. Click to set vertex 4.

</details>

<details>
<summary><img src="/guide-icons/geometry_square.svg" alt="Square icon" /> Square</summary>

**How to create it:**
1. Click to set vertex 1.
2. Click to set the base.
3. Click to choose which side the square falls on.

</details>

<details>
<summary><img src="/guide-icons/geometry_rectangle.svg" alt="Rectangle icon" /> Rectangle</summary>

The same three-click flow as Square, with each side sized independently.

**How to create it:**
1. Click to set vertex 1.
2. Click to set the base.
3. Click to choose the rectangle's side.

</details>

<details>
<summary><img src="/guide-icons/geometry_parallelogram.svg" alt="Parallelogram icon" /> Parallelogram</summary>

**How to create it:**
1. Click to set vertex 1.
2. Click to set vertex 2.
3. Click to set vertex 3 — the 4th vertex is deduced automatically.

</details>

<details>
<summary><img src="/guide-icons/geometry_rhombus.svg" alt="Rhombus icon" /> Rhombus</summary>

**How to create it:**
1. Click to set vertex 1.
2. Click to set the side length.
3. Click to choose the second side's direction.

</details>

<details>
<summary><img src="/guide-icons/geometry_polygon.svg" alt="Polygon icon" /> Polygon</summary>

A closed shape with as many vertices as you click.

**How to create it:**
1. Click to add each vertex, in order.
2. Once you have 3 or more vertices, press `Enter` (or keep clicking) to finish.

</details>

</details>

<details>
<summary>Curves (3)</summary>

<details>
<summary><img src="/guide-icons/geometry_ellipse.svg" alt="Ellipse icon" /> Ellipse</summary>

**How to create it:**
1. Select or place the center.
2. Select or place the major-axis point.
3. Select or place the minor-axis point.

</details>

<details>
<summary><img src="/guide-icons/geometry_arc.svg" alt="Arc icon" /> Arc</summary>

**How to create it:**
1. Select or place the arc's start point.
2. Select or place the arc's end point.
3. Select or place a point the arc passes through.

</details>

<details>
<summary><img src="/guide-icons/geometry_parabola.svg" alt="Parabola icon" /> Parabola</summary>

**How to create it:**
1. Select or place the parabola's start point.
2. Select or place the parabola's end point.
3. Select or place the vertex.

</details>

</details>

<details>
<summary>Constructions (8)</summary>

<details>
<summary><img src="/guide-icons/geometry_tangent.svg" alt="Tangent icon" /> Tangent</summary>

One or both tangent lines from a point to an existing circle.

**How to create it:**
1. Click an existing point, or place a new one.
2. Click the circle to draw tangents to.
3. Approve each tangent line as it previews (up to 2).

</details>

<details>
<summary><img src="/guide-icons/geometry_tangent_at_point.svg" alt="Tangent at Point icon" /> Tangent at Point</summary>

A tangent line touching a circle at one specific point.

**How to create it:**
1. Click the circle to select it.
2. Click the contact point on the circle (snaps to points already on it).
3. Set the first endpoint of the tangent line.
4. Set the second endpoint of the tangent line.

</details>

<details>
<summary><img src="/guide-icons/geometry_intersection.svg" alt="Intersection icon" /> Intersection</summary>

A point wherever two existing segments cross.

**How to create it:**
1. Click the first segment.
2. Click the second segment.

</details>

<details>
<summary><img src="/guide-icons/geometry_extend_segment.svg" alt="Extend Segment icon" /> Extend Segment</summary>

Extends an existing segment past one of its endpoints.

**How to create it:**
1. Click the segment to extend.
2. Click along its direction to set how far to extend it.

</details>

<details>
<summary><img src="/guide-icons/geometry_perpendicular.svg" alt="Perpendicular Drop icon" /> Perpendicular Drop</summary>

A dashed line dropped from a point straight onto a line, with a right-angle marker where it lands.

**How to create it:**
1. Select the point to drop the perpendicular from.
2. Select the line to drop it onto.

</details>

<details>
<summary><img src="/guide-icons/geometry_perp_bisector.svg" alt="Perpendicular Bisector icon" /> Perpendicular Bisector</summary>

**How to create it:**
1. Select the line segment to bisect.
2. Place the first endpoint of the bisector line.
3. Place the second endpoint of the bisector line.

</details>

<details>
<summary><img src="/guide-icons/geometry_angle_bisector.svg" alt="Angle Bisector icon" /> Angle Bisector</summary>

**How to create it:**
1. Select or place the angle's vertex.
2. Select or place a point on the first ray.
3. Select or place a point on the second ray.
4. Set the bisector's endpoint, or snap it to a side.

</details>

<details>
<summary><img src="/guide-icons/geometry_parallel_line.svg" alt="Parallel Line icon" /> Parallel Line</summary>

**How to create it:**
1. Select the line segment to draw parallel to.
2. Click to set how far away the parallel line sits.
3. Click to set the parallel line's start point.
4. Click to set its end point.

</details>

</details>

## Math & Logic

7 types, all reachable from the **Math & Logic** tab of the Add Object Bar.

<details>
<summary><img src="/guide-icons/polyline.svg" alt="Polyline Tool icon" /> Polyline Tool</summary>

An open, multi-segment line through as many points as you click.

**How to create it:**
1. Click to start the polyline.
2. Click to add each additional point.
3. Press `Enter` (or keep clicking) to finish.

</details>

<details>
<summary><img src="/guide-icons/brace.svg" alt="Brace icon" /> Brace</summary>

A curly brace spanning between two points.

**How to create it:**
1. Click the tail point.
2. Click the tip point.

</details>

<details>
<summary><img src="/guide-icons/arrow.svg" alt="Arrow icon" /> Arrow</summary>

**How to create it:**
1. Click the tail point.
2. Click the tip point.

</details>

<details>
<summary><img src="/guide-icons/dashed_arrow.svg" alt="Dashed Arrow icon" /> Dashed Arrow</summary>

The same as Arrow, drawn with a dashed stroke.

**How to create it:**
1. Click the tail point.
2. Click the tip point.

</details>

<details>
<summary><img src="/guide-icons/fill_region.svg" alt="Fill Region icon" /> Fill Region</summary>

A filled color region bounded by existing lines and curves — not a freeform shape of its own.

**How to create it:**
1. Click inside an area enclosed by existing geometry to select it as a region.
2. Click more enclosed areas to add them, or double-click to finish.

</details>

<details>
<summary><img src="/guide-icons/cubic_bezier.svg" alt="Bezier icon" /> Bezier</summary>

A cubic Bezier curve with four control points.

**How to create it:**
1. Click **Bezier** in the Add Object Bar — it's placed immediately with four default control points.
2. Drag its points, or use the floating toolbar's Edit Points editor, to reshape the curve.

</details>

<details>
<summary><img src="/guide-icons/parametric_function.svg" alt="Function icon" /> Function</summary>

A plotted curve from a mathematical expression (defaults to *y = sin(x)*).

**How to create it:**
1. Click **Function** in the Add Object Bar — it's placed immediately with the default expression.
2. Use the floating toolbar's Edit Curve editor to change the expression.

</details>
