# Animation Types

Every animation reachable from the Floating Toolbar — one entry each. Select an object (or objects) on the canvas first, then open the Floating Toolbar to apply any of these.

## ![Create icon](/guide-icons/create.svg) Create

**What it does:** Makes the selected object appear on screen — the default entrance animation for anything you create.

**How to trigger it:**
1. Select the object.
2. Open the Floating Toolbar.
3. Click **Create**. Click the small arrow on the button instead to pick a specific variant — **Fade In**, **Grow In**, or **Draw** — rather than the default.

## ![Destroy icon](/guide-icons/destroy.svg) Destroy

**What it does:** Removes the selected object from the canvas at the end of the animation.

**How to trigger it:**
1. Select the object.
2. Open the Floating Toolbar.
3. Click **Destroy**.

## ![Move icon](/guide-icons/move.svg) Move

**What it does:** Records a move from the object's current position to wherever you drag it next.

**How to trigger it:**
1. Select the object.
2. Open the Floating Toolbar and click **Move** (or press `Shift`+`W`) to arm the move gizmo.
3. Drag the object to its new position.

## ![Rotate Around icon](/guide-icons/rotate-around.svg) Rotate Around

**What it does:** Revolves the object around a pivot point without spinning the object itself.

**How to trigger it:**
1. Select the object.
2. Open the Floating Toolbar and click **Rotate Around**.
3. Click on the canvas to set the pivot point.
4. Drag around the pivot to set the rotation angle, then release.

## ![Rotate icon](/guide-icons/rotate.svg) Rotate

**What it does:** Revolves the object around a pivot point while also spinning the object by that same angle.

**How to trigger it:**
1. Select the object.
2. Open the Floating Toolbar and click **Rotate**.
3. Click on the canvas to set the pivot point.
4. Drag around the pivot to set the rotation angle, then release.

## ![Dim In icon](/guide-icons/dim-in.svg) Dim In

**What it does:** Fades the object in from transparent to its normal opacity.

**How to trigger it:**
1. Select the object.
2. Open the Floating Toolbar.
3. Click **Dim In**.

## ![Dim Out icon](/guide-icons/dim-out.svg) Dim Out

**What it does:** Fades the object from its normal opacity down to transparent.

**How to trigger it:**
1. Select the object.
2. Open the Floating Toolbar.
3. Click **Dim Out**.
